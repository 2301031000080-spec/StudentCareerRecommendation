# Student Career Recommendation System

A Flask-based BTech minor project that uses a Decision Tree machine learning model to recommend career paths from a student's assessment profile.

## Current Features

- Student career assessment
- Top 3 career recommendations with match scores
- Professional-field based recommendation filtering
- Career-specific learning resources
- Student profile
- Assessment history
- Retake and compare assessments
- Save / favorite careers
- Career detail pages
- CV / Resume Builder with printable preview
- Pink + purple responsive interface
- Render deployment support

## Technology Stack

- Python
- Flask
- Pandas
- Scikit-learn
- SQLite
- HTML, CSS, JavaScript

## Run Locally

```bash
pip install -r requirements.txt
python app.py
```

Then open `http://127.0.0.1:5000`.

## Project Title

**Student Career Recommendation System**
